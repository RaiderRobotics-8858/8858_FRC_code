
# LED Subsystem

The LED Subsystem helps alert the driver of a change in the game and adds style. These LEDs can also be used to provide feedback during testing and debugging.

## Coding

Initial code for this subsystem is generated by [PhoenixTuner (By CTRE)](https://v6.docs.ctr-electronics.com/en/stable/docs/tuner/index.html). From there, we added commands to support different animations and color presets.

```java
// Example instantiation within RobotContainer.java
private final LEDSubsystem ledSubsystem = new LEDSubsystem();
```

### Tele-op control

Timer-based when the drive starts autonomous mode and change with the phases of the game.

### Autonomous control

Flashes different colors for different points of autonomous mode.

## Electrical

### Interface types

* Controlled through CANdle on **CAN ID 14**
* LED strip is controlled by [WS2812B](https://cdn-shop.adafruit.com/datasheets/WS2812B.pdf)
